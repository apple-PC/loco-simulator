# 电力机车模拟器 · Loco Simulator

第一人称视角的 3D 电力机车驾驶模拟器，单文件 HTML（Three.js r128），直接打开即可运行。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 左键 | 按 3D 按钮 / 合刀开关 |
| 按住手柄拖动 | 推拉换向、牵引手柄（松手吸附档位） |
| 右键 | 反向操作手柄 |
| ↑ ↓ | 牵引档位 0–4 |
| ← → | 换向 前 / 0 / 后 |
| 空格 | 紧急制动 |
| B | 大闸：运转 → 全制 → 紧急 |
| H | 电笛 |
| C | 展开 / 收起开机检查单 |
| 1 / 2 / 3 | 驾驶室 / 车外跟随 / 供电室 |

## 开机流程

1. 合「控制电源」钥匙开关
2. 进供电室，打开 1# 高压柜，合「辅助系统」刀开关
3. 回驾驶室按「受电弓」
4. 再进供电室合「主断路器」
5. 换向手柄推至前位 → 牵引手柄给档

## 特性

- PBR 材质 + ACESFilmic 色调映射，无过曝
- 27° 倾斜操纵台，所有按钮为真实 3D 网格 + Canvas 文字贴图
- 完整联锁逻辑、空气制动时间常数（列车管排风 → 制动缸充风）、电阻制动、恒速
- WebAudio 实时合成：VVVF 变频啸叫、电机低鸣、制动排风、受电弓气动、轨道接缝
- 站台对标评分、调度电台、道岔扳动与信号机联动
- 白天 / 黄昏 / 夜间 / 雨天四套环境
